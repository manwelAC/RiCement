# IoT-Based Rice Husk Ash Production System with Mobile App Control

## 📖 Overview
This repository contains the thesis project **“IoT-Based Rice Husk Ash Production System with Mobile App Control for Sustainable Cement Additive Manufacturing.”**  
The system integrates IoT-enabled hardware with a mobile application to automate the mixing and dispensing of cement with rice husk ash (RHA) for non-load bearing hollow blocks. It aims to improve efficiency, consistency, and sustainability in small-scale cement additive manufacturing.

---

## 🎯 General Objective
To develop an IoT-based production system with mobile app control that automates the mixing and dispensing of cement with rice husk ash for non-load bearing cement hollow blocks, ensuring efficiency, consistency, and improved quality in small-scale manufacturing.

---

## ✅ Specific Objectives
1. Collect user input and control commands through the mobile application for system operations.  
2. Calculate rice husk ash, cement, and water as raw materials for the hollow block mixture.  
3. Combine accurately the cement, rice husk ash, and water into a uniform mixture using the specific unit of measurements built into the app.  
4. Dispense the mixed ingredients into a hollow block mold.  
5. Control and monitor the mixing and dispensing processes in real-time using the app.  
6. Enable cloud-based production logging, system status monitoring, and alert notifications via the mobile app.  
7. Mold high-quality, consistent, non-load bearing hollow blocks incorporating rice husk ash as a sustainable cement additive.  
8. Provide detailed production records and operational status reports accessible to small-scale manufacturers.  
9. Produce hollow blocks with rice husk ash after the molding process.  

---

## 📌 Scope
- Design and implement an IoT-enabled motorized mixing system that combines cement, rice husk ash, and water.  
- Develop a mobile application that enables remote control and monitoring of the mixing and dispensing processes.  
- Automatically dispense the ingredients in making cement mixture for hollow blocks.  
- Provide production logging and status monitoring features through the mobile application for tracking efficiency and output.  
- Predict using AI how many hollow blocks to be used per project/house based on square meters.  
- Real-time monitoring and notification, including alerts for low raw materials, process completion, and system status updates accessible through the mobile application.  

---

## ⚠️ Limitations
- The system will not include the burning or production of rice husk ash; it will only use pre-processed RHA as an input material.  
- The prototype will be limited to small-scale hollow block production using size 4 hollow blocks and may not meet the volume capacity of industrial systems.  
- The prototype will be limited to one hollow block per process.  
- The system will be limited to Android devices only.  

---

## 🛠️ Tech Stack
- **IoT Hardware:** Sensors, motorized mixing unit, dispensing mechanism  
- **Mobile App:** Android-based control and monitoring interface  
- **Cloud Services:** Logging, notifications, and production records  
- **AI Integration:** Hollow block usage prediction per project
